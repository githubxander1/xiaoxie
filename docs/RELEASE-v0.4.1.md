# 小歇 v0.4.1 · 休息提醒调度修正

Windows 便携版，解压后运行 `小歇.exe`。需要 Windows 10 / 11 与 .NET Framework 4.8。

## 本次更新

- 修复轻声模式可能长期推迟远眺提醒的问题，远眺按设定参考间隔获得优先处理。
- 修复点击完成后，普通提醒绕过档位间隔、缩短为每两分钟一次的问题。
- 改善主题排序和组合关怀，避免其他健康主题长期被挤后。
- 修复自定义文案组合时遗漏部分主题内容的问题。
- 新安装默认较长休息：参考六十分钟，练习五分钟。已有设置保留，可在「关怀」页自行调整。
- 保留自动财经快讯、一言、桌宠与隐藏模式。

## 检查

39 项本地检查与 5 项联网检查通过；额外使用三个档位、五十个随机种子的连续使用模拟复核提醒节奏。

各项默认分钟数、参考依据与模拟条件见 [休息间隔评审](https://github.com/githubxander1/xiaoxie/blob/main/docs/REMINDER-INTERVALS.md)。

## 下载与升级

下载 `Xiaoxie-v0.4.1-windows-portable.zip`。升级请先退出旧版，保留原 `Data` 文件夹再替换程序；如启用开机启动并移动目录，需要重新设置。

`SHA256SUMS.txt` 提供便携包校验值。当前程序未做代码签名；财经源为公开 RSS 中转，可能延迟或临时不可用。
