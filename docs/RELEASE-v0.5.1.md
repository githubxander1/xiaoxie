# 小歇 v0.5.1 · 随机动作与简化反馈

Windows 便携版，解压后运行 `小歇.exe`。

## 本次更新

- 自动提醒从到期项目中加权随机选择，有其他候选时避免连续重复；保留远眺到期保护及各项开关。
- 肩部、双手、支撑和舒展等具体动作轮换，提醒与打开的练习一致。
- 互动中的“健康小练习”随机选择已开启的动作组，不再固定远眺。
- 点击反馈后直接生效，移除“收到啦 → 好”二次弹窗。
- 练习倒计时结束自动收起并更新对应计时；提前收起不算完成。

## 检查

50 项本地检查与 5 项联网检查，覆盖随机选择、避免重复、已关闭项目、远眺调度、旧设置迁移和新闻解析。

## 升级

退出旧版，保留原 `Data` 文件夹，替换程序即可。需要 Windows 10 / 11 与 .NET Framework 4.8。

下载 `Xiaoxie-v0.5.1-windows-portable.zip`，校验值见 `SHA256SUMS.txt`。
