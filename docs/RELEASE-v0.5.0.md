# 小歇 v0.5.0 · 四类关怀，更少重复提醒

Windows 便携版，解压后运行 `小歇.exe`。需要 Windows 10 / 11 与 .NET Framework 4.8。

## 本次更新

- 提醒合并为四类：用眼休息、姿势放松、离座休息、饮水。
- 移除如厕功能及对应旧配置、自定义文案。
- 眨眼融入用眼休息；肩膀、双手、双脚支撑和轻柔舒展成为姿势组的轮换内容。
- 起身走动与较长休息合并，默认参考六十分钟，离屏休息五分钟。
- 确认离座休息完成后，联动更新用眼、姿势和离座；饮水仅在明确反馈时更新。
- 自动迁移旧开关、间隔和自定义文案，保留作息、新闻设置和位置。
- 可选每天一次的开工检查，默认关闭；也可从菜单手动打开。
- 继续保留自动财经快讯、语录、桌宠、极简小点和隐藏模式。

## 检查

45 项本地检查与 5 项联网检查；包含旧配置迁移、文案保留、禁用状态、远眺调度和休息联动。

## 升级

先退出旧版，保留原 `Data` 文件夹，再替换程序。四组间隔优先使用可迁移的旧值；新安装默认为用眼二十、姿势三十、离座六十、饮水六十分钟。

下载 `Xiaoxie-v0.5.0-windows-portable.zip`。`SHA256SUMS.txt` 提供校验值。当前程序未做代码签名；财经源为公开 RSS 中转，可能延迟或临时不可用。
