# 小歇 v0.4.0

Windows 桌面健康伙伴，支持小猫陪伴、极简悬浮和托盘隐藏。

## 功能

- 十类健康关怀，支持工作时段、空闲、全屏和手动暂停。
- 温柔、俏皮、简短三种语气，可自定义文案。
- 摸摸、伸懒腰、鼓励与原创小段子。
- 可选远眺、活动等倒计时练习，完成后由用户确认。
- 自动快讯独立计时，默认约 8–12 分钟随机展示一条近期未读内容。
- 支持金十、华尔街见闻 RSS 中转，以及 BBC中文、IT之家和自定义 RSS。
- 一言语录与台词；在线内容可分别关闭。
- 长文案支持换行和滚动阅读。

## 运行

解压便携包，运行 `小歇.exe`。需要 Windows 10 / 11 和 .NET Framework 4.8。

升级请先退出旧版，保留 `Data` 文件夹后替换程序。未做代码签名；财经 RSS 中转可能有延迟或临时不可用。

## 检查

本版提供 32 项本地检查和 5 项联网检查。联网检查结果受外部服务可用性影响。
