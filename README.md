**忙碌的桌面，也留一点时间给自己。**

## 这是什么

小歇是一只可以住在桌面角落的小猫。它会用自然的短句提醒你看看远处、放松双手、起身走走，也能分享一句台词或一条财经快讯。

你可以让它展开陪伴、收成一个小点，或者完全隐藏到系统托盘。提醒出现时，小歇会根据你选择的“做到了”“现在忙”等反馈，调整后续关怀。

健康关怀和原创互动在本地运行；在线语录、新闻可以分别开关。使用健康功能无需账号或 AI API 密钥。

## 功能

| 功能 | 说明 |
| --- | --- |
| 三种显示方式 | 展开小猫、极简小点、隐藏到托盘；支持拖动和缩放 |
| 四类健康关怀 | 远眺、眨眼、坐姿、饮水、走动、手部放松、双脚支撑等 |
| 有反馈的提醒 | 休息、饮水、完成小动作分别更新；忙碌时可以安静陪伴 |
| 小练习 | 远眺、肩部、双手等动作随机轮换，计时结束自动收起 |
| 轻互动 | 摸摸、伸懒腰、鼓励和原创办公室小段子 |
| 自动快讯 | 独立计时，从近期未读内容中随机展示一条，保留来源和时间 |
| 语录与台词 | 一言语录，支持诗词、文学、动漫、影视；离线时有本地短句 |
| 可定制文案 | 温柔、俏皮、简短三种语气；也可以逐个主题编写文案 |
| 工作时段 | 工作日、上下班、午休、锁屏、全屏、空闲与手动暂停 |
| 便携运行 | 解压使用，设置和内容缓存存放在本机 |

### 健康关怀

| 分组 | 内容 | 默认参考 |
| --- | --- | --- |
| 用眼休息 | 远眺、自然眨眼 | 20 分钟，远眺 20 秒 |
| 姿势放松 | 肩膀、双手、手腕、背部与双脚支撑，轻柔舒展 | 30 分钟，组内轮换内容 |
| 离座休息 | 起身走动、离屏休息 | 60 分钟，休息 5 分钟 |
| 饮水 | 按自己的需要补充水分 | 60 分钟，接近离座休息时可合并 |

原有眨眼、双手、双脚、轻活动不再各自计时。如厕功能已移除。开工检查作为可选的每日一次事件，默认关闭，不占用第五个定时项。

关怀综合参考电脑使用时间、空闲状态、工作时段和你的反馈。主题可以合并，文案会轮换；并非每个主题都单独弹一个固定闹钟。

几种反馈的含义：

| 操作 | 小歇会怎么做 |
| --- | --- |
| 一起做一下 | 打开对应小练习，计时结束自动收起并更新对应计时 |
| 做到了 | 更新当前主题；包含离座休息时，联动更新用眼、姿势和离座 |
| 刚休息过 | 更新用眼、姿势和离座，饮水单独保留 |
| 喝过水了 | 只更新饮水反馈 |
| 现在忙 | 暂时安静，连续选择会适当延长 |
| 关闭或未回应 | 不视为已经完成，也不等同于主动要求长时间暂停 |

程序无法判断真实坐姿、实际饮水量或身体状态。提醒是一般性关怀，参考分钟数可以按个人习惯调整。

## 快速开始

### 使用便携版

1. 在 [Releases](https://github.com/githubxander1/xiaoxie/releases) 获取便携包。尚无发行包时，可以按下文从源码构建。
2. 解压到有写入权限的文件夹，运行 `小歇.exe`。
3. 首次打开按自己的作息调整设置，点击“保存”。

运行需要 **Windows 10 / 11 和 .NET Framework 4.8**。当前程序未做代码签名。

### 日常操作

| 操作 | 结果 |
| --- | --- |
| 点击小猫 | 打开互动气泡 |
| 拖动小猫或小点 | 改变位置 |
| 滚轮滚动 | 调整展开时的小猫大小 |
| 右键小猫 | 收起、隐藏、互动、小练习、设置、暂停和退出 |
| 点击收起的小点 | 展开小猫 |
| 双击托盘图标 | 打开设置 |
| 关闭设置窗口 | 继续在后台运行 |
| 托盘菜单“退出” | 完全退出程序 |

托盘图标可能位于 Windows 的隐藏图标区域。长文案支持换行和滚动；鼠标停留在正文时，会暂停气泡自动收起。

## 自动快讯

**开启后不需要点击“读条新闻”。**

正常启动约一分钟后尝试展示第一条；之后默认以 **10 分钟**为参考，随机在约 **8–12 分钟**之间展示一条近期未读内容。

在 **设置 → 内容** 中可以调整：

- 自动快讯的开关。
- 参考间隔：2–180 分钟。
- 是否让间隔上下浮动两成。
- 新闻来源、自动语录的开关与独立间隔。

保存并关闭设置窗口后，自动展示才会继续。遇到健康关怀会顺延；锁屏、暂停、全屏、午休或非工作时段也会保持安静。恢复后只展示一条，不补发积压。

### 支持的来源

| 来源 | 接入方式 |
| --- | --- |
| 财经混合，默认 | 金十与华尔街见闻之间随机选择；失败时尝试另一来源 |
| 金十快讯 | 公开 RSS 中转 |
| 华尔街见闻快讯 | 公开 RSS 中转 |
| BBC中文 | RSS |
| IT之家 | RSS |
| 自定义 | RSS、Atom、兼容的 DailyHotApi JSON 地址 |

自动快讯从近八小时内的未读内容选择，优先使用最新十五条候选；已读内容去重。发布时间由来源提供；缺少发布时间时，显示获取时间。使用旧缓存时会明确标注。

财经来源为**第三方 RSS 中转**，并非金十官方实时 API，可能有缓存、延迟或临时不可用。内容保留来源与链接，点击后由浏览器打开。接入说明与参考项目见 [SOURCES.md](SOURCES.md)。

## 休息间隔是否合理

v0.5.2 自动健康提醒、新闻和语录默认以约 280×68 的小条显示，8 秒自动收起；悬停暂停收起，点击文字或箭头展开完整内容及操作。完整提示框宽度缩至约 320，长内容可滚动阅读。以上尺寸随系统缩放调整。

v0.5.1 在到期项目中随机选择主提醒，有其他到期项目时避免连续重复；远眺到期仍会合并提醒。互动里的健康小练习也会随机轮换。反馈直接生效，不再追加确认弹窗；练习计时结束自动收起并更新对应计时，提前收起不算完成。

v0.5.0 将提醒合为四类，并联动更新离座休息后的计时。v0.4.1 的调度修正继续保留：远眺参考二十分钟，不再因轻声模式和其他主题长期延后；普通提醒不会因为点击完成就绕过所选频率。新安装默认每六十分钟建议一次五分钟离屏休息。

已有配置保留。如旧配置仍为较长休息一百二十分钟，可在「关怀」页自行改为六十分钟。具体间隔是软件偏好，可按自己的工作和实际需要调整。各项参考、依据、旧版问题和模拟条件见 [休息间隔评审](docs/REMINDER-INTERVALS.md)。

## 个性化设置

| 页面 | 可调整内容 |
| --- | --- |
| 陪伴 | 名字、语气、关怀频率、显示方式、每日开工检查 |
| 关怀 | 四个分组的开关和参考分钟 |
| 文案 | 每行一句；留空使用内置文案；支持 `{名字}` |
| 内容 | 自动快讯、来源、在线语录及分享间隔 |
| 时段 | 工作日、工作时间、午休、空闲、全屏、声音与开机启动 |

默认工作时间为周一至周五 **09:00–18:00**，午休为 **12:00–13:30**。提示音、开机启动和每日开工检查默认关闭。在线语录、新闻获取和自动快讯默认开启，可以分别关闭。

## 数据与隐私

- 健康关怀、互动文案和图形在本地运行。
- 在线内容请求只发给所选来源，不发送健康反馈、键入内容或屏幕画面。
- 不使用摄像头，不录制屏幕，不读取具体键入内容。
- 空闲判断使用键鼠最近操作的时间；全屏判断使用窗口尺寸。

默认数据目录位于程序旁的 `Data` 文件夹；目录不可写时使用 `%LOCALAPPDATA%\RestBuddy`。

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 作息、文案、显示方式等设置 |
| `settings.json.bak` | 上次保存的设置备份 |
| `content-cache.json` | 公共语录、新闻缓存和已读标记 |

关怀积累、暂停状态只保留在当前运行会话。便携发行包和源码仓库均不包含个人配置。

升级时先退出旧版，保留 `Data` 文件夹后替换程序。

v0.5.0 会将旧提醒自动归入四组：任一组内旧项开启，该组保持开启；参考分钟优先使用开启的主项，未开启主项时使用其他已开启旧项。相关自定义文案合并去重，作息、新闻设置和小猫位置保留；已删除项目的配置和文案会移除。首次迁移后的设置会保留上次保存的备份。

新安装离座休息默认六十分钟；升级沿用可迁移的旧间隔。如需采用新默认，可在设置里调整。移动程序目录后，如启用了开机启动，请关闭并保存，再重新启用。卸载前也应先取消开机启动并退出，然后删除程序目录。

## 源码构建

项目使用 **C#、Windows Forms 和 GDI+**。小猫由代码绘制，构建使用 Windows .NET Framework 自带的 C# 编译器。

在 Windows PowerShell 中执行：

```powershell
git clone https://github.com/githubxander1/xiaoxie.git
cd xiaoxie
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build\小歇.exe
```

构建会生成 `build/小歇.exe`，以及供检查脚本引用的 `build/RestBuddy.exe`。发布便携版时使用 `小歇.exe` 即可。

### 开发检查

```powershell
# 本地逻辑与内容解析
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run.ps1

# 额外检查五个在线来源
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run.ps1 -Network
```

检查产物和报告保存在 `build/checks`。当前包含 **50 项本地检查和 5 项联网检查**；公网服务发生超时或故障时，联网检查可能失败。

### 目录结构

```text
src/             应用、关怀逻辑、桌宠绘制、内容获取与设置
tests/           逻辑、解析、自动快讯和联网检查
assets/          项目标识
docs/            发行说明
build.ps1        Windows 本机构建脚本
app.manifest     Windows 应用清单
SOURCES.md       接口来源与健康内容参考
```
